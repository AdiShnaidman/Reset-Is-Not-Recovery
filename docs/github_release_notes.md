# GitHub Release Notes

This repository contains the reproducibility artifacts for
"Reset Is Not Recovery: Evaluating Recoverability from False Conversational
Context via Sycophancy Hysteresis."

The paper was accepted at GroundLM, an EMNLP 2026 Workshop (non-archival).

Repository:
'https://github.com/AdiShnaidman/Reset-Is-Not-Recovery'

The release includes prompts, data subsets, scripts, aggregate results,
metrics, and table-generation artifacts needed to reproduce the reported
paper tables from the saved artifacts.
